# 📝 Markdown Live Preview

**Component**: `src/sidepanel/tools/MarkdownPreview.tsx`  
**Styles**: `src/sidepanel/tools/MarkdownPreview.css`

## Overview

Side-by-side GitHub-flavored markdown editor and live HTML renderer.

## Features

- **GitHub Flavored Markdown (GFM)**: Tables, task lists, strikethrough, autolinks, fenced code blocks with language syntax highlighting.
- **Dual Pane View**: Real-time synced preview while typing.
- **HTML Export**: Inspect raw rendered HTML source and copy clean HTML with one click.
- **Cheat Sheet Drawer**: Fast access to markdown formatting syntax and examples.
