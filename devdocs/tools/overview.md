# 🛠️ Developer Tools Catalog

`hckr` packages 11 developer utilities directly inside the browser side panel.

| Tool | Component | Key Features |
| :--- | :--- | :--- |
| 🗄️ **[JSON Formatter](/devdocs/tools/json-formatter/)** | `JsonFormatter.tsx` | Prettify, minify, sort keys, tree view, syntax highlighting, invalid JSON error locators. |
| 🔑 **[JWT Decoder](/devdocs/tools/jwt-decoder/)** | `JwtDecoder.tsx` | Header/payload decoding, expiry timer, human-readable claim formats, signature validation visualizer. |
| 🔤 **[Base64 Tool](/devdocs/tools/base64/)** | `Base64Tool.tsx` | UTF-8 text & URL-safe base64 encoding/decoding, file-to-data-URI converter. |
| 🌐 **[URL Encoder](/devdocs/tools/url-encoder/)** | `UrlEncoder.tsx` | Encode/decode query params, path parsing, interactive query parameter key-value table editor. |
| 🔒 **[Hash Generator](/devdocs/tools/hash-generator/)** | `HashGenerator.tsx` | SHA-256, SHA-512, SHA-1, MD5, HMAC calculation using Web Crypto API. |
| 🆔 **[UUID Generator](/devdocs/tools/uuid-generator/)** | `UuidGenerator.tsx` | Bulk v4 UUID generator, ULID, NanoID, uppercase/lowercase formatting. |
| ⏱️ **[Timestamp Converter](/devdocs/tools/timestamp-converter/)** | `TimestampConverter.tsx` | Epoch to ISO-8601/UTC/Local, relative duration, live clock, milliseconds toggle. |
| 🔀 **[Diff Checker](/devdocs/tools/diff-checker/)** | `DiffChecker.tsx` | Side-by-side & unified text diffing with word/character level highlighting. |
| 🔍 **[Regex Tester](/devdocs/tools/regex-tester/)** | `RegexTester.tsx` | Real-time match highlighting, regex flag toggles (`g`, `i`, `m`, `s`), match groups visualizer. |
| 🎲 **[Dummy Data Generator](/devdocs/tools/dummy-data/)** | `DummyDataGenerator.tsx` | Schema-based dummy JSON/CSV generation (names, emails, addresses, numbers, UUIDs). |
| 📝 **[Markdown Preview](/devdocs/tools/markdown-preview/)** | `MarkdownPreview.tsx` | Real-time GitHub-flavored markdown preview, HTML source view, copy rendered HTML. |
