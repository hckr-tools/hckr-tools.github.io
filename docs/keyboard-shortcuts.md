# Keyboard Shortcuts

hckr is optimized for rapid keyboard-driven developer workflows.

## Global Shortcuts

| Shortcut | macOS | Windows / Linux | Action |
| :--- | :--- | :--- | :--- |
| **Open Sidepanel** | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> | Toggle the hckr side panel |
| **Quick Tool Search** | <kbd>Cmd</kbd> + <kbd>K</kbd> | <kbd>Ctrl</kbd> + <kbd>K</kbd> | Open the tool launcher palette |
| **Copy Output** | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> | Copy the active tool result to clipboard |
| **Clear Input** | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> | Clear current input buffer |

## Customizing Keybindings

You can customize the shortcut to trigger the hckr side panel at any time:
1. Open `chrome://extensions/shortcuts` in Google Chrome.
2. Scroll to **hckr — Developer Utility Toolkit**.
3. Click the pencil icon next to **Activate the extension** and set your desired key sequence.
