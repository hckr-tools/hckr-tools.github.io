# Dummy Data Generator

Generate synthetic test datasets in JSON, CSV, or SQL formats.

## Overview

The **Dummy Data Generator** runs entirely inside your browser side panel. No data is transmitted over the network, making it safe for proprietary tokens, logs, and sensitive payloads.

## Key Features

- **Instant Results**: Live evaluation as you type or paste.
- **1-Click Copy**: Fast clipboard integration with feedback.
- **Smart Formatting**: Handles edge cases, invalid inputs, and whitespace automatically.
- **Dark Mode Native**: Seamlessly matches your browser and system preferences.

## Usage Guide

1. Open the **hckr** side panel (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> on macOS / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> on Windows).
2. Select **Dummy Data Generator** from the sidebar or press <kbd>Cmd</kbd>+<kbd>K</kbd> to quick-search.
3. Paste or type your input in the editor.
4. Copy the result directly to your clipboard.
