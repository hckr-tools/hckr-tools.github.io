# Tools Catalog Overview

hckr bundles a comprehensive suite of utilities for daily software engineering:

| Tool | Category | Key Capabilities |
| :--- | :--- | :--- |
| **[JSON Formatter](/docs/tools/json-formatter/)** | Data | Format, minify, repair trailing commas, evaluate JMESPath / JSONPath |
| **[JWT Decoder](/docs/tools/jwt-decoder/)** | Security | Decode header/payload, inspect claims, humanize epoch expiration |
| **[Base64 Encoder/Decoder](/docs/tools/base64/)** | Encoding | Standard & URL-safe Base64, hex & text conversion |
| **[URL Encoder/Decoder](/docs/tools/url-encoder/)** | Encoding | Full URL component encoding/decoding, query param breakdown |
| **[Hash Generator](/docs/tools/hash-generator/)** | Security | MD5, SHA-1, SHA-256, SHA-512, HMAC with live typing |
| **[UUID / NanoID Generator](/docs/tools/uuid-generator/)** | Generators | v1, v4, v7 UUIDs, NanoID, bulk generation with custom separators |
| **[Timestamp Converter](/docs/tools/timestamp-converter/)** | Time | Seconds/milliseconds epoch conversion, relative time, ISO-8601, timezone matrix |
| **[Diff Checker](/docs/tools/diff-checker/)** | Text | Side-by-side & unified diff viewer with word-level changes |
| **[Regex Tester](/docs/tools/regex-tester/)** | Text | Live matching, capture group inspector, regex cheat sheet |
| **[Dummy Data Generator](/docs/tools/dummy-data/)** | Generators | Generate mock JSON, SQL, or CSV datasets (names, emails, addresses, UUIDs) |
| **[Markdown Previewer](/docs/tools/markdown-preview/)** | Text | Live GitHub Flavored Markdown renderer with table & code highlight support |
