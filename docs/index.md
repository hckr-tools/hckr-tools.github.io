# Welcome to hckr ⚡

**hckr** is an offline-first developer utility toolkit built directly into your Chrome browser side panel. Stop pasting sensitive tokens, JSON payloads, and credentials into random online web formatters.

## Why hckr?

- 🔒 **100% Offline & Private**: Zero analytics, zero telemetries, and zero network calls. All computations run in-memory within your browser process.
- ⚡ **Sidepanel Native**: Stays docked alongside your code editor, postman, terminal, or browser tab without obscuring your view.
- 🧠 **Context-Aware Detection**: Highlight text on any page (JWT, Epoch timestamp, Base64 string, JSON blob) to automatically inspect or decode it in the sidepanel.
- 🚀 **12+ Essential Tools**: JSON formatting & filtering, JWT debugging, Unix timestamps, Regex testing with live highlights, Diff checking, and much more.
